# SAR 舰船判读基础手册（内置示例资料）

> 本文件为「文档问答」功能的内置示例资料。导入后可向 Agent 提问，
> 例如："手册里说虚警的常见来源有哪些？"Agent 会检索并引用本文件作答。

## 1. 舰船目标特征

- 舰船在 SAR 图像上通常表现为**亮斑**：金属船体是强散射体，后向散射显著高于海面背景。
- 大型船只常伴生**船尾迹**（湍流尾迹与开尔文尾迹），呈细长亮/暗线，可用于辅助定位与运动方向估计。
- **阴影区**：船体背向雷达一侧形成暗区，阴影长度与船高、入射角相关，可用于估算目标尺度。

## 2. 典型场景判读

| 场景 | 目标分布特征 |
|---|---|
| 港口/码头 | 目标密集，沿泊位规则排列，朝向一致，常伴随岸线强回波与角反射效应 |
| 锚地 | 目标较多且间距均匀，朝向多样，离岸一定距离，常伴小艇往返 |
| 开阔海面 | 目标稀疏孤立，可能伴随机船尾迹，背景以海杂波纹理为主 |

## 3. 虚警与漏检

- **虚警常见来源**：波浪亮点（Bragg 波）、浮标、养殖网箱、岛礁边缘、船尾迹误判为多目标。
- **漏检常见原因**：目标尺寸过小、弱散射（木质/玻璃钢船体）、强海杂波掩盖、图像边缘裁切。
- **复核建议**：低置信度检测框需结合斑点噪声水平与局部杂波背景判断；降低置信度阈值可提高召回，但虚警会同步上升。

## 4. 成像与术语

- **斑点噪声（Speckle）**：相干成像固有的乘性颗粒噪声，常用 Lee/Kuan 滤波抑制。
- **方位向/距离向**：平台运动方向 / 雷达波发射方向；SAR 图像分辨率在两个方向上分别受天线孔径与带宽决定。
- **入射角**：波束与水平面夹角，入射角越大海面回波越弱、目标阴影越长。
- **海况**：海面风浪等级，高海况下杂波增强，小目标可检测性下降。
- **RCS（雷达散射截面）**：目标散射强度的度量，舰船 RCS 与吨位、结构、姿态角相关。

## 5. 检测结果复核流程建议

1. 先看目标数量与分布是否符合该区域的先验（渔港/军港/锚地/航道）；
2. 对低置信度框逐个核对：尺寸是否合理、有无对应阴影或尾迹；
3. 对比不同时相检测结果，关注新增（进港/抵达）与消失（离港）目标；
4. 输出报告时注明检测阈值与模型版本，保证结论可复现。
